# Deploy Implementation Plan (3 of 3: server, web, deploy)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Push to `main` → Cloud Build builds the server image, deploys Cloud Run, builds the web bundle, deploys Firebase Hosting. Cloud Scheduler drives `/internal/tick`. Spec: `docs/superpowers/specs/2026-08-11-game-server-design.md`.

**Project:** `fluted-citizen-269819` (billing enabled; APIs enabled; Firestore `us-central1` and Artifact Registry repo `www` already created on 2026-08-11).

## Global Constraints

- Region `us-central1` everywhere. Cloud Run service name `www-api`, min 0 / max 1 instance.
- Secrets only in Secret Manager (`resend-api-key`); never in the repo or build logs.
- The tick route is authenticated by OIDC from a dedicated SA `www-tick@…`; `TICK_SERVICE_ACCOUNT` and `TICK_AUDIENCE` env vars on Cloud Run.
- Hosting rewrites `/api/**` and `/internal/**` are NOT both needed — only `/api/**`; the scheduler calls the Cloud Run URL directly.

## Prerequisites (blocked on human)

- [ ] Firebase added to the project (console ToS acceptance) → then `firebase projects:addfirebase fluted-citizen-269819` succeeds or is unnecessary.
- [ ] Google sign-in provider enabled: console → Authentication → Sign-in method → Google → Enable.
- [ ] Resend account + API key + verified sender (or skip: LogMailer runs when `RESEND_API_KEY` is unset).

### Task 1: Containerize the server

**Files:** Create `Dockerfile`, `.dockerignore` (repo root — build context needs the whole workspace).

Multi-stage: `node:22-slim` → corepack pnpm install → `pnpm build` → prune to production deps (`pnpm deploy --filter @www/server --prod`) → runtime stage copying the deployed dir; `CMD ["node", "dist/main.js"]`; `ENV NODE_ENV=production`. Verify locally: `docker build -t www-api .` then run with `FIRESTORE_EMULATOR_HOST=host.docker.internal:8080` against running emulators and hit `/healthz`.

### Task 2: Firebase config for Hosting + web app

**Files:** Modify `firebase.json` (add hosting section: `public: packages/web/dist`, SPA rewrite to `/index.html`, `/api/**` → run service `www-api`), create `.firebaserc` (`{"projects": {"default": "fluted-citizen-269819"}}`).

Steps: `firebase apps:create web www-web` → `firebase apps:sdkconfig web` → write real values into `packages/web/.env.production` (`VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN` = `fluted-citizen-269819.firebaseapp.com`, `VITE_FIREBASE_PROJECT_ID`). These are public identifiers, safe to commit.

### Task 3: Service accounts, scheduler, secrets

```
gcloud iam service-accounts create www-tick
gcloud secrets create resend-api-key --replication-policy automatic   (+ add version when key exists)
# runtime SA for Cloud Run: default compute SA needs roles/datastore.user + secretmanager.secretAccessor
gcloud scheduler jobs create http www-tick --schedule "* * * * *" \
  --uri https://<run-url>/internal/tick --http-method POST \
  --oidc-service-account-email www-tick@fluted-citizen-269819.iam.gserviceaccount.com \
  --oidc-token-audience <run-url> --location us-central1
```

Run deploy env: `GCP_PROJECT`, `BASE_URL=https://<hosting-domain>`, `TICK_AUDIENCE=<run-url>`, `TICK_SERVICE_ACCOUNT=www-tick@…`, `MAIL_FROM`, secret `RESEND_API_KEY`.

### Task 4: cloudbuild.yaml + trigger

Steps: docker build+push `us-central1-docker.pkg.dev/fluted-citizen-269819/www/api:$COMMIT_SHA` → `gcloud run deploy www-api --image … --region us-central1 --allow-unauthenticated --min-instances 0 --max-instances 1 --set-secrets RESEND_API_KEY=resend-api-key:latest --set-env-vars …` → node step: corepack pnpm install + build web (`--mode production`) → `firebase deploy --only hosting --project fluted-citizen-269819` (firebase-tools via npx; Cloud Build SA needs `roles/firebasehosting.admin`, `roles/run.admin`, `roles/iam.serviceAccountUser`, `roles/artifactregistry.writer`).
Trigger: GitHub App connection to `topherhooper/WorldWideWar`, branch `^main$`. (Connecting the repo is a console step — human.)

### Task 5: First deploy + smoke test

Manual `gcloud builds submit` first (no trigger needed), then: sign in on the hosted URL with a real Google account, create a 2-player game, start with bots, lock orders, confirm resolution + `/internal/tick` firing in logs, confirm no seed/order leakage in network tab.
