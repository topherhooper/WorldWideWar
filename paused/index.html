World Wide War

Paused

The game is asleep. Turn deadlines have stopped firing, so nothing you submit here would resolve — which is why there is nothing to submit.

Every finished game and every game caught mid-turn is kept exactly as it was. The pause freezes the clock; it does not end anything. When the site comes back, the games come back with it.

If you were told a game was running, it is waiting rather than lost. Ask whoever sent you the link.
